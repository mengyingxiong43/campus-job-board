# applytracker 安装说明（发行版）

> 版本：v1.0（定稿）｜作者：许清楚（产品）｜日期：2026-10-07
> **本稿状态**：十步全部定稿。文末依赖清单里的各项实现已基本落地（启动脚本版本校验 + 中文提示、端口兜底、邮箱直连、机会库首启预置均已上线）；仅剩浏览器扩展「自动探测端口」待扩展侧实现。
> 配套：`docs/安装说明-大纲.md`（骨架）、`docs/PRD-发行版.md`（需求）。

**按顺序做一遍，大约 15 分钟。全程你不需要打开命令行、不需要输入任何命令——所有操作都是「双击一个文件」或者「在网页上点按钮」。**

---

## 开始之前

**这份说明给谁看**：没装过 Python、没用过命令行的同学。

**开始前请准备好**：

- 一台自己的电脑（Windows 或 macOS）。
- 一个常用的邮箱（**推荐 QQ 邮箱或 163 邮箱**；Gmail / Outlook 也能用，但要多做一步）。
- 大概 15 分钟。

**包里有什么（先认个脸）**：

| 你会看到 | 它是什么 | 你要对它做什么 |
|----------|----------|----------------|
| `applytracker.py` | 看板程序本体 | 不用管，启动文件会调用它 |
| `start.command` | macOS 的启动文件 | macOS 双击它起看板 |
| `start.bat` | Windows 的启动文件 | Windows 双击它起看板 |
| `extension/` | 浏览器扩展文件夹 | 装扩展时选这个文件夹 |
| `data/` | 存你记录的地方 | 不用管，但要知道**它就是你数据的家**（见第九步） |
| `docs/` | 说明文档 | 迷路时回来翻 |

**两个提醒**：

1. 整个 `applytracker` 文件夹要**整份放好、别拆开**。放「文稿 / Documents」或桌面都行，**别放在「下载」里**（下载夹容易被清理）。
2. 这个工具**不联网也能用**，也**不需要注册任何账号**。你的所有数据都只在你自己的电脑里。

## 第一步：把文件放好

### 你会看到什么

从压缩包解压后，可能会多出一层文件夹（比如「下载」里出现一个 `applytracker-发行版`，点进去里面还有个 `applytracker`）。

### 你要做什么

1. 把最外层那个文件夹拖到「**文稿 / Documents**」（或桌面）。
2. 点进去看一眼：里面应该有 `applytracker.py`、`start.command`、`start.bat`、`extension` 文件夹。

### 卡住了怎么办

- **点进去还是只看到一层同名文件夹**：再双击进去一层，直到看到上面那些文件为止。
- **不确定放哪**：放「文稿 / Documents」最保险。

## 第二步：装 Python

**这一步是整个安装里最容易卡住的地方，请慢一点看。**

### 你会看到什么

- 如果还没装 Python 就双击了启动文件：Windows 上可能是一个黑窗口一闪就没了；macOS 上可能弹一句「没找到 python3」。
- 这些都说明：**电脑上还没有 Python，或者版本太旧**。

### 你要做什么

1. **先确认装没装、版本对不对**。最省事的办法是打开工具自带的**环境检测**页面，它会直接告诉你「已就绪 / 没装 / 版本太低」。（如果你没有这个页面，就直接按第 2 步装一遍。）
2. **没装就去装**（打开下面的官方下载页，不需要你会搜）：
   - **macOS**：访问 python.org 的下载页，下载 **3.9 或更高**版本的安装包，双击一路「继续」；
   - **Windows**：访问 python.org 的下载页，下载安装包。**安装窗口最下面有一个「Add python.exe to PATH」的勾选项，务必勾上**，再点 Install。
3. 装完回到本项目，**双击启动文件继续往下走**。

### 卡住了怎么办

- **Windows 双击 `start.bat`，黑窗口一闪就没**：八成是上一步漏勾了「**Add python.exe to PATH**」。修法——重新运行一遍 Python 安装包，选「Modify / 修改」，找到 PATH 选项勾上；实在找不到就卸载后重装，**记得勾**。
- **macOS 系统可能自带一个 `python3`**，但版本可能偏旧或不完整，**最稳妥的就是自己装一遍官方包**。
- **装完还是提示没找到**：**重启一次电脑**再试（新设置有时要重开环境才生效）。
- **还是不行**：把出问题的那个窗口**截图**，发给你身边会一点电脑的同学，或发给出这个工具的人。别只说「打不开」，把截图发出去，一眼就能看出问题。

## 第三步：确认文件放对了

### 你会看到什么

打开 `applytracker` 文件夹，一眼能同时看到 `applytracker.py` 和 `start.command`（macOS）或 `start.bat`（Windows）。

### 你要做什么

1. 确认你在**正确的这一层**：能看到上面那些文件，就对了。
2. 如果只看到「一个文件夹，名字也叫 applytracker」，再双击进去一层。

### 卡住了怎么办

- **找不到 `applytracker.py`**：说明你还在外层，进去一层即可。
- **文件夹里文件很多、拿不准**：找 `start.command`（macOS）或 `start.bat`（Windows）——它在就说明位置对了。

## 第四步：起服务

### 你会看到什么

- macOS：双击 `start.command`，弹出一个终端窗口，里面打几行字；电脑准备好之后，浏览器自动打开看板。
- Windows：双击 `start.bat`，弹出一个命令行窗口；电脑准备好之后，浏览器自动打开看板。
- **如果电脑还没准备好**（没装 Python、Windows 漏勾了「Add to PATH」、或 macOS 自带的 Python 版本太旧），**脚本不会一闪而过**——它会**停在那里**，用中文告诉你哪里不对，等你按一下回车才关闭。你会看到下面三种提示之一：

| 你会看到的提示 | 它的意思 | 你该做什么 |
|----------------|----------|------------|
| 「没找到 Python，先装一个再试」 | 这台电脑没装 Python，或者系统找不到它 | 回到**第二步**装 Python（Windows 记得勾 Add to PATH），再双击一次 |
| （Windows）提示 Python 没在 PATH 里 / 让你先去装 Python | 装了 Python，但安装时**没勾**「Add python.exe to PATH」 | 重新运行 Python 安装包 → 选「Modify / 修改」→ 勾上 PATH；或卸载重装并记得勾选 |
| 「Python 版本太低，需要 3.9 或更高」 | 电脑上的 Python 太旧（macOS 系统自带那个常见） | 去 python.org 装一个 **3.9 或更高**的版本 |

> 说明：上面这三条中文提示，是启动脚本**正在补上**的能力。如果你手上的版本还没补，看到的是英文报错或一句看不懂的失败信息——那**不是你的操作错了**，按上表对应那一行处理（去装 / 重装 Python）即可。

### 你要做什么

1. macOS 双击 `start.command`；Windows 双击 `start.bat`。
2. 等浏览器自己弹出（一般几秒）。
3. **那个黑窗口（终端窗口）不要关**——它就是看板正在运行。你可以把它最小化。

### 卡住了怎么办

- **macOS 提示「无法打开，因为它来自身份不明的开发者」**：不要双击，改成**右键（或按住 Control 再点）→ 打开 → 再点「打开」**；或到「系统设置 → 隐私与安全性」里点「仍要打开」放行。
- **看到上面那张表里的三种提示之一**：按对应的「你该做什么」处理，然后重新双击启动文件。
- **窗口里说端口被占用**：看第五步的处理办法。
- **窗口一关，看板就打不开了**：这是正常的。想用时重新双击启动文件即可，数据不会丢。

## 第五步：打开看板

### 你会看到什么

浏览器自动打开 `http://127.0.0.1:8788`，看到三个标签页：**投递进度 / 邮箱通知 / 机会库**。第一次打开「投递进度」「邮箱通知」可能是空的，这是正常的（还没投、还没连邮箱）。**「机会库」不用等**：首次启动会自动把随包带的公开岗位库（9381 条）导入进来，打开就有。

### 你要做什么

1. 如果浏览器没自动弹，手动在地址栏输入：`http://127.0.0.1:8788`。
2. 认一下三个标签页（顺便记住它们各管什么）：
   - **投递进度**：你投过的每一家、什么状态；
   - **邮箱通知**：从你自己邮箱抓来的测评/面试/offer 通知；
   - **机会库**：随包带的一份校招岗位汇总，可筛。

### 卡住了怎么办

- **提示「无法访问此网站」**：①确认上一步的窗口还开着；②确认地址是 `127.0.0.1:8788`，不是别的。
- **上一步的窗口里说「端口被占 / 改跑在 …」**：说明 8788 被别的程序占了（也可能是你之前已经开着一个看板）。
  **这种情况你不用做任何事**：程序会在 8788–8791 里挑一个空的自己换过去，并在窗口里**打印实际用的端口**
  （比如「端口 8788 被占，看板改跑在 8790」）；**浏览器扩展也会自己找过去**，你不需要改任何代码或配置。
  只有 8788–8791 **四个全被占**时才会停下来报错 —— 那时候关掉一个占端口的程序再双击一次就行。
  （如果你自己想指定端口，用 `--port 9000`；注意这种情况下程序**只在你要的那一个端口上试一次**，
  被占就报错、不会自己漂到别的端口。）
- **以为要联网 / 要登录**：不用。`127.0.0.1` 就是**你自己电脑**的地址，不上网、不注册、数据只在你机器里。

## 第六步：连上你自己的邮箱

> **这一步可以跳过。** 不配也能用看板的另外两栏。配好了，「邮箱通知」这一栏才会活起来。

**重要：邮箱和看板是同一个程序——你只需要配这一次，不用再起第二个服务。**

### 你会看到什么

**首选：直接在页面上连（不用打开命令行）。** 打开看板的「邮箱通知」页，如果还没接邮箱，页面顶部会有一个「**连接我的邮箱**」按钮——点它，在弹出的卡片里填**邮箱地址**和**授权码**，点「连接」。看板会当场去登录试一下，成功就自动开始收邮件。旁边有个「怎么拿授权码？」的折叠说明，按你的邮箱类型照着做就行。认不出的邮箱（比如学校邮箱）在「服务商」下拉里选「其他邮箱」，手填一下收信服务器地址。

**备选：终端向导。** 习惯命令行的话，也可以在终端跑 `python3 applytracker.py --mail-config`，效果一样（填邮箱 + 授权码，当场验证）。

配好之后，它每次会自己去收新邮件，抽出发给你们的测评/面试/offer 通知，放进「邮箱通知」页。

### 你要做什么（以 QQ 邮箱为例，最快的一条路）

1. 电脑浏览器登录 QQ 邮箱，点右上角「**设置**」→「**账号与安全 / 账户**」。
2. 找到「**POP3/IMAP/SMTP/Exchange/CardDAV 服务**」这一块，点「**开启**」。
3. 按提示用**绑定的手机发一条短信**验证；通过后，页面会弹出一串 **16 位的授权码**。
4. **立刻把这串授权码复制下来**——它只显示这一次，关掉就没了。没存下的话，回设置里**重新生成一个**就行（旧的会作废）。
5. 回到看板：点「连接我的邮箱」，填你的邮箱地址、粘贴这串**授权码**，点「连接」。

### 卡住了怎么办

- **一直登录失败**：最常见的原因是——**填成了邮箱的登录密码**。这里要填的是**授权码，不是登录密码**。
- **不知道在哪开、找不到设置入口**：看**附录 A**，QQ / 163 / Gmail / Outlook 各有一张分步说明。
- **Gmail 用户**：比 QQ 多一步——**必须先开启「两步验证」**，然后生成一个「**应用专用密码**」（16 位），用它当授权码。
- **163 用户**：名词不一样，163 那边叫「**客户端授权密码**」，步骤类似（设置 → POP3/SMTP/IMAP → 开启 → 生成）。
- **完全不想连 / 现在配不动**：不点「连接我的邮箱」就行。看板会显示「邮箱通知还没接」的提示条，**不报错、不空白**，你随时可以回来点那个按钮。

## 第七步：装浏览器扩展

### 你会看到什么

装好后，浏览器右上角多出一个扩展图标。点开它，能看到「**服务已连接**」。

### 你要做什么

1. 浏览器地址栏输入 `chrome://extensions`（Edge 用户输入 `edge://extensions`）后回车。
2. 打开页面**右上角**的「**开发者模式**」开关（打开后页面会多出几个按钮）。
3. 点页面**左上角**出现的「**加载已解压的扩展程序**」。
4. 在弹出来的选择框里，**选中 `extension` 这个文件夹本身**（不是它外面的 `applytracker`），确定。
5. 扩展图标出现后，点开确认显示「**服务已连接**」。

### 卡住了怎么办

- **找不到「开发者模式」开关**：它在扩展页面的**右上角**。
- **报错「清单文件缺失」/「Manifest file is missing」**：**一定是第 4 步选错了文件夹**。要选的是 `applytracker/extension`，**选成 `applytracker` 就错了**。
- **显示未连接**：①回第四步确认看板还开着；②**扩展会自动找到看板服务的端口，你不需要改任何代码或配置**——如果它自己没找到，按弹窗里的提示操作即可。
- **浏览器更新后扩展不见了 / 被停用**：重新进 `chrome://extensions` 确认它还在、开关是打开的；若浏览器提示是否保留，选择保留。
- **用的是 Edge 或其他 Chromium 浏览器**：路径一样，扩展页地址换成 `edge://extensions`。

## 第八步：投一次，试试闭环

### 你会看到什么

在招聘官网点完「提交申请」后，页面右下角会弹出一张小卡片：**公司名、岗位、链接都已经帮你填好**，下面还有一格可以写备注（内推码、HR 说的回复时限都行）。点「记下来」，这条就进了「投递进度」。

### 你要做什么

1. 照常去官网投一家，点完提交后留意右下角。
2. 卡片弹出来，看一眼公司名对不对，对就点「**记下来**」；不是你要记的就点「忽略」。
3. 回到看板的「投递进度」页，确认这条记录在里面。

### 卡住了怎么办

- **投完没弹卡**：用页面右边的「**记一笔**」标签，或点扩展图标 →「记录当前页」，两秒手记一条。这两条路不依赖自动识别，任何时候都能用。
- **公司名认错了，或者空着**：在投递进度表里**点一下那一格就能改**，改完立刻生效，没有「保存」按钮。第一次记一家新公司最可能留空，你手填对一次，以后这家就能自动认出来了。
- **记录没进看板**：①确认第四步的看板还开着、扩展显示「服务已连接」；②看板每 10 秒自己刷新一次，等一下或刷新页面。

## 第九步：你的数据在哪、怎么备份

**这一节请务必看一眼——它决定你的记录会不会丢。**

### 你会看到什么

你的所有记录，其实是 `applytracker/data` 文件夹里的几张表（最主要的是 `data/applications.csv`）。

### 你要做什么

1. 记住一句话：**你的投递记录在 `applytracker/data/applications.csv`**。
2. **备份**：把整个 `data` 文件夹复制走就是备份（复制到 U 盘、网盘都行）。
3. **想手动看 / 改**：`applications.csv` 可以用 **Excel 或 WPS 直接打开**。

### 卡住了怎么办

- **换电脑 / 重装系统**：把整个 `applytracker` 文件夹拷过去就行（配置和数据都在里面）。
- **担心记录被上传**：不用担心。**所有记录只在你本机**，没有任何数据发往外部；邮箱授权码也只存在你本机的一个配置文件里。

## 第十步：看一眼机会库

### 你会看到什么

「机会库」页里有 **9381 条**校招岗位信息（随包带好，**首次启动自动导入，你不需要配置任何东西**），能按行业 / 城市 / 批次筛，也能只看还没截止的。**打开就有。**

### 你要做什么

- 直接筛着用。看到想投的岗位，点「投递入口」去官网投，投完扩展照常帮你记录。

### 需要知道的（预期管理）

- **这是「发版那一天」的数据快照，不会自动更新**（页面顶部会标注「数据截至 X 月 X 日」）。
- 想看更新的招聘信息，请以官方招聘渠道或相关汇总渠道为准。

## 常见问题

- **看板能离线用吗？** 能。联网只在你选择连邮箱时会用到。
- **同事/室友能通过局域网看到我的看板吗？** 不能。服务只绑在你自己电脑上（`127.0.0.1`），同一个 Wi-Fi 下别人也访问不到。
- **能装好几台电脑吗？** 可以，每台各装一套、各连各的邮箱，互不影响。
- **记录会被上传到任何地方吗？** 不会，全部在你本机。
- **黑窗口关了怎么办？** 重新双击启动文件即可，数据不会丢。
