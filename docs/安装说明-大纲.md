# applytracker 发行版 · 安装说明大纲

> 版本：v0.1（大纲稿）｜作者：许清楚（产品）｜日期：2026-10-07
> 性质：这是《安装说明》（给同学看的正式文档）的**大纲与写作骨架**，不是最终文案。每步给到「用户看到什么 / 要做什么 / 卡住了怎么办」三要素，可直接据此扩写成正式说明，也可作为**首次启动引导页**的分屏结构。

## 写作原则（放文首，也决定整篇的语气）

1. **说人话，不说术语**。写「那个黑窗口不要关」，不写「请保持进程驻留」。凡出现「命令行 / 端口 / PATH」这类词，必须紧跟一句大白话解释。
2. **每个可能失败的地方，都给一条「卡住了怎么办」**。同学的绝大多数放弃不是因为难，是因为卡住时不知道去哪问。
3. **允许跳过**。邮箱那一步配不下来可以跳过，程序照常用（通知页写明「怎么回来配」）——不许把可选步骤做成硬门槛。
4. **两条系统路径分开写**，用 macOS / Windows 标签区分，绝不合在一起让人自己猜。
5. 全文**不使用 emoji 作功能图标**；必须指路的地方用「引号里的按钮名字」或截图高亮。

## 开始之前

**这份说明给谁看**：没装过 Python、没用过命令行的同学。全程你**不需要**打开命令行、不需要输入任何命令——所有操作都是「双击一个文件」或「在网页上点按钮」。

**开始前，请先准备好三样**：

- 一台自己的电脑（Windows 或 macOS）。
- 一个常用的邮箱（**推荐 QQ 邮箱或 163 邮箱**；Gmail / Outlook 也能用，但要多做一步）。
- 大概 15 分钟。

**包里有什么（先认个脸）**：

| 你会看到 | 它是什么 | 你要对它做什么 |
|----------|----------|----------------|
| `applytracker.py` | 看板程序本体 | 不用管，双击脚本会调用它 |
| `start.command` | macOS 的启动文件 | macOS 双击它起看板 |
| `start.bat` | Windows 的启动文件 | Windows 双击它起看板 |
| `extension/` | 浏览器扩展文件夹 | 装扩展时选这个文件夹 |
| `data/` | 存你记录的地方 | 不用管，但**要知道它就是你数据的家**（见第 8 步） |
| `docs/` | 说明文档 | 迷路时回来翻 |

> **重要**：整个 `applytracker` 文件夹要**整份放好、别拆开**。放到「文稿 / Documents」，或桌面都行，但**别放在「下载」里**（下载夹容易被系统或清理软件清空）。

## 第一步：装 Python（三大放弃点之首，要重点写）

### 用户看到什么
- 如果什么都没做就双击 `start.bat`：一个黑窗口一闪就没了；双击 `start.command`：可能弹「无法打开，因为它来自身份不明的开发者」，或提示 `没找到 python3`。

### 要做什么
1. **先判断装没装 / 版本对不对**（引导页第一屏可自动检测，文档里给手动版）：
   - 打开一次命令行看一眼也行，但**更推荐让引导页自己检测**，把结果直接显示成「已就绪 / 没装 / 版本太低」。
2. **没装就去装**（给两条直达路径，不让人自己搜）：
   - macOS：访问 python.org 下载页，下载 **3.9 或更高** 的安装包，双击一路「继续」。
   - Windows：访问 python.org 下载页，下载安装包，**安装时第一步务必勾上底部的「Add python.exe to PATH」**，再点 Install。
3. **装完回到本项目，重新双击启动文件**。

### 卡住了怎么办
- **Windows 双击 `start.bat`，黑窗口一闪就没** → 八成是第 2 步漏勾了「Add python.exe to PATH」。修法：重新运行一遍 Python 安装包 → 选「Modify / 修改」→ 找到 PATH 选项勾上；或卸载后重装并记得勾选。
- **macOS 系统可能自带一个 `python3`**，但版本可能偏旧或不完整，**最稳妥就是自己装一遍官方包**。
- **装完还是提示没找到 → 重启一次电脑再试**（PATH 生效有时要重开环境）。
- 还不行：把黑窗口里的**原文**截图，发给出这个工具的同学（不要只说「打不开」，要说清截图）。

> 写作提醒：这一节要配**三张图**——①下载页；②Windows 安装第一步的高亮（圈出 Add to PATH）；③装成功后引导页显示「环境已就绪」的样子。

## 第二步：确认文件放对了位置

### 用户看到什么
- 解压后可能多出一层文件夹（例如「下载」里出现 `applytracker-发行版`，里面才是 `applytracker`）。
- 打开解压出来的文件夹，能看到 `applytracker.py`、`start.command`、`start.bat`、`extension` 文件夹。

### 要做什么
1. 把**最外层**那个文件夹拖到「文稿 / Documents」（或桌面）。
2. 点进去，确认**一眼能同时看到** `applytracker.py` 和 `start.command`（macOS）或 `start.bat`（Windows）。
3. 如果看到的是「里面还套着一层同名文件夹」，就再点进去一层，直到看到上面那些文件为止。

### 卡住了怎么办
- **找不到 `applytracker.py`** → 说明你还在外层，再双击进去一层。
- **不确定放哪** → 放「文稿 / Documents」最保险（不会被系统清理）。

## 第三步：起服务（三大放弃点之一）

### 用户看到什么
- macOS：双击 `start.command`，会弹出一个黑（白）色的**终端窗口**，里面打几行字，然后浏览器自己打开看板。
- Windows：双击 `start.bat`，弹出一个**命令行窗口**，随后浏览器自动打开看板。

### 要做什么
1. macOS 双击 `start.command`；Windows 双击 `start.bat`。
2. **等浏览器自己弹出**（一般 2～5 秒）。
3. **那个黑窗口不要关**——关掉它，看板就停了。你可以把它最小化。

### 卡住了怎么办
- **macOS 提示「无法打开，因为它来自身份不明的开发者」** → 不要双击，改成**右键（或 Control + 点按）→ 打开 → 再点「打开」**；或到「系统设置 → 隐私与安全性」里点「仍要打开」放行。
- **macOS 双击没反应 / 提示没有权限执行** → 说明解压把「可执行权限」弄丢了。让有基础的同学帮着把该文件设成「可执行」，或改用命令行运行（可放到附录给进阶用户）。
- **Windows 双击闪退** → 回到第一步（Python 没进 PATH）。
- **提示端口被占用 / 8788 起不来** → 说明已经开着一个了，或别的程序占了。①先看是不是已经开着看板（在浏览器打开 `http://127.0.0.1:8788` 试试）；②仍不行，按脚本提示换一个端口，换完记得**扩展那边也要同步**（见第五步的注意事项）。
- **窗口一关，看板就打不开了** → 正常。要用的时候重新双击即可。想让它「开机就在」，见附录（macOS 有现成脚本，Windows 进 Backlog）。

## 第四步：打开看板

### 用户看到什么
- 浏览器自动打开 `http://127.0.0.1:8788`，看到三个标签页：投递进度 / 邮箱通知 / 机会库。**第一次打开各页可能是空的，正常。**

### 要做什么
1. 没自动弹就手动在浏览器输入地址：`http://127.0.0.1:8788`。
2. 认一下三个标签页分别是什么（给一句话说明 + 一张全景图）。

### 卡住了怎么办
- **提示「无法访问此网站」** → ①确认第三步的黑窗口还开着；②确认地址是 `127.0.0.1:8788`，不是别的。
- **以为要联网 / 要注册账号** → 明确写：「这是**你自己电脑上的地址**，不需要联网、不需要注册，数据只在你电脑里」。

## 第五步：装浏览器扩展（三大放弃点之一）

### 用户看到什么
- Chrome / Edge 右上角出现一个新的扩展图标。
- 点开图标，能看到「服务已连接 / 未连接」。

### 要做什么
1. 浏览器地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）回车。
2. 打开页面**右上角**的「**开发者模式**」开关（打开后会多出几个按钮）。
3. 点页面**左上角**出现的「**加载已解压的扩展程序**」。
4. 在弹出的选择框里，**选中 `extension` 这个文件夹本身**（不是它外面的 `applytracker`），确定。
5. 扩展图标出现后，点开确认「服务已连接」。

### 卡住了怎么办
- **找不到「开发者模式」开关** → 它在 `chrome://extensions` 页面的**右上角**（配图高亮）。
- **报错「清单文件缺失」或「Manifest file is missing」** → 100% 是第 4 步选错了文件夹。要选的是 `applytracker/extension`，**选到 `applytracker` 就错了**。
- **“服务已连接”显示未连接** → ①第三步的服务没起（回去看第三步）；②改过端口的话，扩展默认连 `8788`，需要让它对齐——**发行版应做到自动发现或图形化填端口，而不是让同学改代码**（此为产品要求，见 PRD 非功能项）。
- **浏览器更新后扩展被停用/消失** → 重新进 `chrome://extensions` 确认它还在、开关是开的；「开发者模式」装的扩展有时会被浏览器提示，选择「保留」即可。
- **Edge / 其他 Chromium 浏览器** → 路径同理，扩展页是 `edge://extensions`。

## 第六步：连上你自己的邮箱（可跳过，但强烈建议）

> **这一步是「邮箱通知」这一栏能不能用起来的关键。配不下来可以跳过，看板的另外两栏照常用。**

### 用户看到什么
- 第一次运行（或点「邮箱通知」页里的「去配置」）时，弹出一个**配置向导**：先问邮箱地址，再问「授权码」，填完它当场去登录试一下，告诉你成功还是失败。

### 要做什么（以 QQ 邮箱为例，最短路径）
1. 电脑浏览器登录 QQ 邮箱 → 右上角「**设置**」→「**账号与安全 / 账户**」。
2. 找到「**POP3/IMAP/SMTP/Exchange/CardDAV 服务**」区域，点「**开启**」。
3. 按提示用**绑定手机发一条短信**验证，通过后弹出**一串 16 位的授权码**。
4. **立刻把这串授权码复制下来**（它只显示这一次，关掉就没了；没存下就重新生成一个）。
5. 回到向导，填邮箱地址 + 这串授权码，让它试登录。

### 卡住了怎么办
- **一直登录失败** → 最常见的原因：**把「邮箱登录密码」填进去了**。这里要填的是**授权码，不是登录密码**（重点加粗、加警示色）。
- **授权码关掉后看不到了** → 回邮箱设置里**重新生成一个**，旧的作废即可。
- **找不到设置入口** → 每种邮箱给一张**独立的分步图文页**（QQ / 163 / Gmail / Outlook 各一页，见附录 A）。
- **Gmail 用户** → 比 QQ 多一步：**必须先开启「两步验证」**，然后生成「应用专用密码」（16 位），再用它当授权码。
- **163 用户** → 名词不一样：163 叫「**客户端授权密码**」，步骤类似（设置 → POP3/SMTP/IMAP → 开启 → 生成授权密码）。
- **完全不想连邮箱** → 点「跳过」。通知页会显示「邮箱没连上，点这里去配置」，不报错、不空白到底。

## 第七步：投一次，试试闭环

### 用户看到什么
- 在招聘官网点完「提交申请」，页面右下角弹出一张小卡片：公司名、岗位、链接已帮你填好，底下有一格可写备注。
- 点「记下来」后，回看板「投递进度」页，能看到这条记录。

### 要做什么
1. 照常去官网投一家，提交后看卡片弹不弹。
2. 弹出的卡片看一眼公司名对不对，对就点「记下来」。
3. 回到看板刷新确认记录在。

### 卡住了怎么办
- **投完没弹卡** → 用右边的「**记一笔**」标签，或扩展图标 →「记录当前页」，两秒手记一条（这两种方式不依赖识别）。
- **公司名认错了 / 空着** → 看板表格里**点一下那格就能改**，改完即存，没有「保存」按钮。第一次记一家新公司最可能留空，手填对一次以后就认得出了。
- **记录没进看板** → ①确认第三步的服务还开着、扩展显示「服务已连接」；②看板每 10 秒自己刷新一次，等一下或刷新页面。

## 第八步：知道你的数据在哪、怎么备份（重要但容易被忽略）

### 用户看到什么
- 你的所有记录，其实是 `data` 文件夹里的几张表（主要是 `data/applications.csv`）。

### 要做什么
1. 记住这句话：**你的投递记录在 `applytracker/data/applications.csv`**。
2. 想备份：**把这个 `data` 文件夹整个复制走**就是备份（比如复制到 U 盘或网盘）。
3. 想手动看/改：`applications.csv` 可以用 **Excel 或 WPS 直接打开**改。

### 卡住了怎么办
- **换电脑 / 重装怎么办** → 把整个 `applytracker` 文件夹拷过去即可（配置和数据都在里面）。
- **担心被上传** → 明确写：**所有记录只在你本机**，没有任何数据发往外部（含邮箱授权码也只存本机配置文件）。

## 第九步：看一眼机会库（了解它的性质）

### 用户看到什么
- 「机会库」页有几千条岗位信息，能按行业 / 城市 / 批次筛，能只看还没截止的。

### 要做什么
- 直接筛着用。想投的岗位点「投递入口」去官网投，投完扩展照常记录。

### 卡住了怎么办 / 预期管理
- **以为它会天天更新** → 明确写：**这是发版那一天的数据快照，不会自动更新**（页顶也会标注「数据截至 X 月 X 日」）。要看更新的信息，去官方招聘渠道或相关汇总公众号。

## 附录 A：四家邮箱拿授权码的对照（正文第六步的展开）

| 邮箱 | 要开什么 | 一步步点哪里 | 那个「码」叫什么 | 额外注意 |
|------|----------|--------------|------------------|----------|
| **QQ 邮箱** | IMAP/SMTP 服务 | 设置 → 账号与安全/账户 → POP3/IMAP/SMTP 服务 → 开启 → 手机短信验证 | **授权码（16 位）** | 只显示一次；填授权码不填登录密码 |
| **163 / 126** | IMAP/SMTP 服务 | 设置 → POP3/SMTP/IMAP → 开启 → 生成 | **客户端授权密码** | 名词不同，别以为不是同一样东西 |
| **Gmail** | 先开两步验证 | Google 账户 → 安全性 → 两步验证（先开）→ 应用专用密码 → 生成（邮件类） | **应用专用密码（16 位）** | 门槛最高，必须先能访问 Google 服务 |
| **Outlook / Microsoft 365** | 两步验证（或 OAuth） | account.microsoft.com/security → 高级安全选项 → 应用密码 → 新建 | **应用密码** | 企业域账号可能更绕 |
