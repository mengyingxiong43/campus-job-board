连接你的邮箱

填邮箱地址和授权码，看板自己收校招通知。数据只在你电脑里，不往外发。

怎么拿授权码？
  • QQ / Foxmail：mail.qq.com → 设置 → 账户 → 开启 IMAP/SMTP 服务 → 短信验证 → 弹窗里的 16 位码
  • 163 / 126：设置 → POP3/SMTP/IMAP → 开启 → 生成「客户端授权密码」
  • Gmail：先开两步验证 → 生成「应用专用密码」（选「邮件」）
  • 其他 / 学校邮箱：问学校 IT 或邮箱服务商；在「服务商」里选「其他邮箱」手填服务器
